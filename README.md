# The Daily AI Drop

A twice-daily AI podcast, generated automatically. Every morning (7 AM CT) and
evening (7 PM CT), the latest videos from fifteen AI YouTube channels are
summarized and discussed by hosts Alex and Jordan.

**Subscribe to the podcast:**

Copy this RSS feed URL into Apple Podcasts, Overcast, Pocket Casts, or any
podcast app:

`https://navdatascience.github.io/daily-ai-drop/feed.xml`

## What's in this repo

- `feed.xml` — the podcast RSS feed (served via GitHub Pages)
- `cover.jpg` — show artwork
- `episodes.json` — episode registry
- `episodes/YYYY-MM-DD/am/` and `episodes/YYYY-MM-DD/pm/` — each edition's
  `episode.mp3` and `notes.md` show notes
