## Surogate 3.7 35B-A3B Locally: Tailing DeepSeek V4 Flash and GLM 5.2 — Fahd Mirza

https://www.youtube.com/watch?v=4Q2q0TNx2SE

Surogate 3.7 is a 35-billion-parameter model built specifically for enterprise agentic applications, and Fahd installs and tests it on his own hardware. The headline comparison is against DeepSeek V4 Flash and GLM 5.2, two of the strongest open models available. It matters because agentic work — multi-step tasks with tool calls — is the workload companies most want to run locally, and a competitive open model in that niche changes the build-versus-buy math.

## GLM-5.4: First Look with Testing — Fahd Mirza

https://www.youtube.com/watch?v=i1zB8Ma75Lg

A genuine first look at GLM-5.4, with almost nothing known about the model beforehand. Fahd runs a two-tab test prompt, a doner skewer visual test, and a test spanning 82 languages. It matters because GLM 5.2 was already being compared with the best open models, so 5.4 arriving this fast shows the pace of the open-model race — and the 82-language test is where many models quietly fall apart.

## LLM vs JEV — Aishwarya Srinivasan

https://www.youtube.com/watch?v=QSV0EdqLlqY

A short clip pointing to a longer video, comparing a plain LLM against Jev — the tool that lets you query a database in plain English using a decision model. It matters for anyone building on top of a database: structure beats vibes when query accuracy matters, and this is the quick version of that debate.
