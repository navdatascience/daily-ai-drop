## Apex-35B Locally: A Model Built by AI Research That Improves Itself — Fahd Mirza

**Link:** https://www.youtube.com/watch?v=tYIvQRlFM6s

Fahd installs and tests Apex-35B-V1.0 on his own hardware, a 35-billion-parameter model built around recursive self-improvement — research that feeds back into the model itself. He walks through the install and real runs so you can judge the self-improving claim in practice rather than from a benchmark chart. It matters because the local open-model race is moving fast: if a model you can run on your own machine keeps getting smarter through its own research loop, that changes who gets to build with frontier-level capability.

## Mastering Context Engineering: Retrieval, Hard Filters, and Multi-Turn Memory — Aishwarya Srinivasan

**Link:** https://www.youtube.com/watch?v=r7ZnrKCjVj4

A practical deep dive into context engineering for production agents, using a shopping assistant as the running example. Aishwarya shows how hybrid search (semantic vector plus keyword), hard metadata filters, and conversational memory across turns fit together into one architecture. This is the skill that separates a demo agent from one you can ship — most agents fail not because the model is weak, but because it is working with the wrong context.
