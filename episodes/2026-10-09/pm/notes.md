### What is a Skill?
- Channel: LangChain
- Link: https://www.youtube.com/watch?v=bv1qgkbWhms
- Published: 2026-10-09 17:11 America/Chicago

LangChain defines a skill as a folder of instructions, scripts, and reference docs for a specific task. Your agent loads only each skill's name and description at startup, then opens the full skill only when a task calls for it. That keeps the context window small, so you spend fewer tokens and your agent runs faster. If your agent gets slower and dumber the longer it runs, this is the fix.
