Three new videos overnight: a tiny model reprogrammed by editing its weights directly, a straight answer to whether you should still learn to code in 2026, and Pika turning images and sound into editable video. Alex and Jordan find the thread connecting them — the shift from prompting to editing.

## Qwen3.5-0.8B Edited: Weight-Space Programming in Action Locally — Fahd Mirza

https://www.youtube.com/watch?v=hYHf4mRZFBw

Fahd installs and tests an edited Qwen3.5-0.8B, a model with fewer than one billion parameters, built with weight-space programming — editing the model's weights directly to program in a behavior, instead of prompting or fine-tuning it. He runs the whole thing locally, on his own hardware. If direct weight editing turns out to be reliable, it changes who gets to shape a model: changing behavior could become closer to editing a document than running a training job. Still experimental, but a public test drive on a downloadable model is how a strange idea becomes a normal tool.

## Should you still learn to code in 2026? #softwareengineering #tech — Aish Reganti

https://www.youtube.com/shorts/d_e96anhlp4

Aish asks whether learning to code is still worth it, starting with Linus Torvalds calling AI "a gateway drug" to programming — it lowers the bar for beginners who might never have started. Linux kernel maintainers recently dropped the "Assisted-by" tag for AI-generated code, a quiet admission that AI help is now just part of how code gets written. The takeaway: learn to code for taste and judgment — knowing what to build and telling good code from bad — not for memorizing syntax. A useful companion to her video yesterday on whether her Carnegie Mellon master's was still worth it.

## Pika turns images and sound into an editable video — Matthew Berman

https://www.youtube.com/shorts/_CQ2QEI63o8

Pika now turns an image and sound into a video you can edit, rather than a clip you have to regenerate until you like the roll. For social posts, ads, and prototypes, the difference between a video you can tweak and one you have to reroll is the difference between a tool and a slot machine. A fast follow-up to Pika H3, which Matthew covered in his roundup last night.
