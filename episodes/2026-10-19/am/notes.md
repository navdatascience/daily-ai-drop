## Priyanka Vergadia — "How Claude reviews its own code"

Anthropic says Claude now writes approximately 90% of Claude Code's own code, which moves the bottleneck from generation to verification — review, testing, merging, and shipping. Priyanka breaks down Anthropic's seven-layer AI code review system built for exactly that problem: when a model writes code at that scale, a human skimming the diff isn't enough. The lesson for anyone running coding agents on their own projects is blunt: invest in review as much as in generation.

https://www.youtube.com/watch?v=aPghvcDM0nc

## LangChain — "Managed Deep Agents explained in 2 minutes"

A two-minute explainer for Managed Deep Agents, LangChain's pitch for the simplest way to build and deploy production agents. You define the agent's intelligence — instructions, tools, skills, the model — and the managed layer underneath handles the agent loop, the filesystem, and the infrastructure. For anyone who has followed the agent framework wars, this is LangChain's answer to how you actually ship an agent without becoming an infrastructure company.

https://www.youtube.com/watch?v=tJ-hlNVS7AI

## Nate B. Jones — "Don't keep shipping"

A punchy short with a productivity core: when you use AI, you're making two choices, and most people blur them together. Which model is about how hard the problem is (a lighter model for a deck or email, a stronger one for hard thinking); the effort setting is how hard the model thinks — like pressing the gas pedal instead of switching cars. Don't keep shipping on the defaults; match both to the task and the output quality changes dramatically.

https://www.youtube.com/watch?v=sIX_c_ayIl4
