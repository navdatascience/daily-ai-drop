## Fahd Mirza — Maxwell V1.0 Flash Tested Locally: 35B MoE, 3B Active, Apache 2.0

https://www.youtube.com/watch?v=RYbe_zfhoyo

Fahd installs and tests Maxwell V1.0 Flash, a new mixture-of-experts model with 35 billion parameters in total but only about 3 billion active at a time, which is why it can run on local hardware. It is released under the Apache 2.0 license, so it can be used commercially. For anyone waiting for a genuinely capable open model they can run themselves without a data center, this is one to watch — the combination of open weights, local runnability, and a permissive license is exactly what the open-model community has been asking for.

## Aish Reganti — Why "Opus Got Nerfed" Claims Often Measure the Wrong Thing

https://www.youtube.com/watch?v=vFDFBmuYQF4

Aish examines recent developer reports that Claude Opus has degraded in reasoning, especially before tool calls, and asks whether Anthropic actually changed the model. She compares individual developer observations against broader dataset trends to test whether the complaints reflect a real change or just the noise of thousands of people using a tool every day. It matters because trust in a model is everything once you build a product on top of it — and vibes are not benchmarks.

## OpenAI — How one engineer built a code review service with Codex | Revolut's Dmitry Pitik

https://www.youtube.com/watch?v=R_sl8zEp9ng

Senior Platform Engineer Dmitry Pitik thought building Revolut's internal code review service would need a whole team of developers. Instead he broke the design into tasks, assigned them to Codex agents working in parallel, and reviewed the code himself. One engineer doing the work of a team, with the human keeping the engineering decisions that actually matter — the most practical agent story of the morning.

## OpenAI — Making seven years of design documentation AI-readable in a day | Revolut's Dmytro Pavlov

https://www.youtube.com/watch?v=hAASMPKkaXA

Revolut's designers had spent seven years documenting how their design system works.
