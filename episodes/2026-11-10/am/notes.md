## AI Can't Handle Law or Finance Jobs Yet — aish_reganti

https://www.youtube.com/watch?v=3Ofzc_x_FPU

GDPx, a new benchmark from SemiAnalysis, tests AI agents on 206 real professional tasks across 11 fields, including finance, law, chip design, and cybersecurity. The best model overall, Claude Opus 5.5, scored 12%, and no model fully completed a single finance task. The finance tasks were built around a reconstructed private equity deal — a fund buying roughly 62% of a snack company — with all the messy documents and judgment calls a real deal involves. If you've been wondering whether AI is about to replace lawyers and bankers, the honest answer this morning is: not yet, not by a long way.

## TwIL LM3 Pro: Logic Model Locally on Contradictions and Reasoning Puzzles — fahdmirza

https://www.youtube.com/watch?v=WapYy-h7Mas

TwIL LM3 Pro is a 3.66-billion-parameter reasoning model built specifically for formal logic tasks, and the key word is "locally" — a small model you can run on your own machine, designed to work through contradictions and reasoning puzzles where big general models often stumble. It's a fun counterpoint to the benchmark story: while giant models score 12% on professional work, a tiny specialist is quietly getting good at one narrow thing. Small, focused models that actually work, running on hardware you own, are a pattern worth watching.

## Kuken Industries searches 70 years of drawings in minutes — OpenAI

https://www.youtube.com/watch?v=FNTz0CdqL6g

Kuken Industries is using the OpenAI API to help engineers search 70 years of drawings in minutes. The system was built with Recursive, a Japanese AI startup and an official OpenAI partner. Nobody is replacing the engineers here — they're getting more time to mentor younger colleagues and take on harder work, because the machine handles the searching. Seventy years of drawings, searchable in minutes: the kind of win that shows up in a real business, not just a demo.

## Microsoft Foundry with Adrian Twarog: Build Your First Agent — MicrosoftDeveloper

https://www.youtube.com/watch?v=-B9pIyQfaSU

Developer and YouTube creator Adrian Twarog takes Microsoft Foundry from first login to a published agent: create an agent, test it in the playground, deploy models, connect an MCP server with scoped permissions, and call the finished agent from the Azure SDK. Microsoft Foundry is where you build, test, and publish AI agents, with usage and billing tracked in Azure. If you've been hearing about agents all year and wondering where the on-ramp is, this is a solid one — especially the part about scoped permissions, because an agent that can only touch what it's supposed to touch is an agent you can actually trust.
