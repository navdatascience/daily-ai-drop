## Inside Clay's GTM agent rebuild — LangChain

https://www.youtube.com/watch?v=efBlbQahwng

Jeff Barg, Head of AI at Clay, explains rebuilding the go-to-market platform's agent around a coding agent that runs on the same command line interface external agents use. With a dataset of 900 million contacts and 40 million companies, this is a production deployment, not a demo. His key claim: Clay got more out of harness engineering than post-training — the scaffolding around the model mattered more than retraining the model. A lesson a lot of teams are learning the expensive way.

## LangSmith Tool Gateway: Secure, Governed Tool Use for Agents — LangChain

https://www.youtube.com/watch?v=achbbrgQnRA

LangSmith Tool Gateway is now in public beta: a managed tool layer that handles credentials, identity, and access for every tool call an agent makes. Agents route requests through a single kit URL with a curated set of tools, so you can govern what each agent is allowed to touch. It sits alongside the LLM Gateway, so LangSmith now governs both model calls and tool calls.

## Can a Better Model Fix a Broken Agent? Look at the Traces — LangChain

https://www.youtube.com/shorts/LZF6VrLm_GE

A short with a point that punches above its weight: a newer model might make your agent a little better, but some problems run deeper than the model. A trace shows everything your agent did on a task, down to each tool call and what every step cost in tokens. Before you pay for a bigger model, look at the trace and find where it actually went wrong.

## Hermes Agent — Businesses Will Pay You to Set Up This Free AI Agent — TheNextNewThingAI

https://www.youtube.com/shorts/iteQX1pP0Jg

## Haru-4B: Worst Speech-to-Speech Full Duplex Model Yet? — Fahd Mirza

https://www.youtube.com/watch?v=zlZGO-mhnLg
